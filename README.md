# CSE 463 — IKEA US Study Lighting Redesign (Pre-Test Prototype v1.0)

Interactive HTML/CSS/JavaScript prototype for **CSE 463 Human–Computer Interaction Final Project (Milestone 1)**.

- **Live Interactive Prototype (GitHub Pages):** https://terrencerli.github.io/cse463-ikea-redesign/
- **Author:** Terrence Li
- **Version:** `v1.0-pretest` (preserved prior to Milestone 2 usability testing)
- **States Covered:** `S1`–`S8` (Catalog & Guided Filter, Product Detail & Configuration, Option/Fulfillment/ZIP Recovery, Shopping Bag & Cost Review, Guest Checkout with Locked Fulfillment, Checkout Validation Recovery, Final Pre-Submission Order Review, and Order Confirmed Receipt).

All catalog inventory, pricing, tax rates, and checkout transactions are simulated locally in the browser for usability testing. Use fictional customer information only.
